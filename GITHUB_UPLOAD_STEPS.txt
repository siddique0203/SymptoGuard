GitHub upload steps

1. Delete the old GitHub repository.
2. Create a new repository with the same name.
3. Open the new repository, click Add file > Upload files.
4. Upload everything inside this folder, not the ZIP file itself.
5. Commit changes.
6. If using Streamlit Cloud, set the main file path to: symptoguard_xai_app.py

Local test command:
streamlit run symptoguard_xai_app.py
